Lean Beginnings

Lean grew out of Leo de Moura's earlier work on SMT solvers, in particular the "Strategy Challenge in SMT Solving" paper — the central idea being white-box control over proof search.

Lean

Created as a platform for white-box automation by Leonardo de Moura

An interactive theorem prover and a functional programming language

Features a lean kernel: a minimised type theory compared to similar systems

Three defining traits: automation, dual nature (prover + programming language), and a small trusted kernel.

The Lean System

The Lean system is more than just the compiler: Lake is the build tool, Reservoir the package registry, Verso powers the reference manual and website, and Loogle helps discover lemmas.

The Liquid Tensor Experiment — 2021

Peter Scholze (Fields Medal 2018) was unsure about one of his latest results in Analytic Geometry.

The Lean community not only verified the proof within months but also simplified it. They did this without fully understanding the entire proof.

Followed by many similar projects since.

Often cited as a watershed moment for computer-assisted mathematics — a leading mathematician trusted a formalisation of his own result.

Software Verification in Lean 4

Lean is not just for pure mathematics. AWS uses it to verify Cedar, their authorisation language, and SampCert verifies a discrete Gaussian sampler used in differential privacy.

Veil Verification Framework (NUS)

github.com/verse-lab/veil

Veil is a distributed-systems verification framework built on Lean. It embeds a small imperative action language inside Lean — exactly the flavour of thing we'll be doing today with Imp.

AI with Lean

DeepMind's AlphaProof reached silver-medal level at the 2024 IMO by translating natural-language problems into Lean and searching for proofs.

Imp: An Imperative Language

Statements: while loops, conditionals, assignment.

Mutable memory; flat mapping from names to 32-bit values (no local scope).

def fact : Stmt := imp { out := 1; while (n > 0) { out := out * n; n := n - 1; } } def swap : Stmt := imp { temp := x; x := y; y := temp; } def min : Stmt := imp { if (x < y) { min := x; } else { min := y; } }

Three programs written in Imp, taken verbatim from Imp/Stmt/Basic.lean. Each lean block is elaborated against the real Imp library — the imp { … } syntax, the operators and the Stmt type all come from Imp/Stmt/Basic.lean and Imp/Expr/Syntax.lean.
